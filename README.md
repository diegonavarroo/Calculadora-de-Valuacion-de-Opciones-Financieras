# Calculadora-de-Valuaci-n-de-Opciones-Financieras
App en Streamlit que valúa 16 opciones financieras (europeas, americanas y exóticas) con el modelo binomial sin dividendos. Adapta entradas según la opción (barreras, rebate, pago fijo o volatilidad), valida no arbitraje y grafica el árbol binomial mostrando el subyacente y el valor/payoff en cada nodo.
